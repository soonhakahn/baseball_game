# 3D 야구: 투구와 타격

브라우저에서 바로 플레이하는 3D 야구 게임입니다. iPhone에서도 됩니다.

**▶ Play Now: https://soonhakahn.github.io/baseball_game/**

Three.js로 만든 브라우저용 3D 야구 게임입니다. 3이닝 경기이고, 타자로 치거나 투수로 던질 수 있습니다. iPhone에서도 탭만으로 플레이합니다.

공개된 야구 규칙과 자체 설계로 만든 오리지널 게임입니다. 실제 구단, 선수, 로고, 다른 게임의 코드나 에셋을 쓰지 않았고, 다른 프로그램을 분석하지도 않았습니다(REA를 사용하지 않음).

## 조작

**타자 모드**
- 화면 위쪽에서 공이 날아옵니다. 공이 홈플레이트에 닿는 순간에 맞춰 공이 지나갈 위치를 탭하면 스윙합니다.
- 탭한 위치의 높이와 가로 위치, 그리고 타이밍이 타구를 결정합니다.
  - 타이밍이 빠르면 당겨 치는 타구(좌익수 쪽), 늦으면 밀어 치는 타구(우익수 쪽)가 됩니다.
  - 공 중심보다 조금 아래를 치면 뜬공, 위를 치면 땅볼이 됩니다.
  - 타이밍과 위치가 모두 맞을수록 타구가 빠르고 멀리 갑니다. 너무 빠르거나 늦으면 파울이나 헛스윙입니다.
- 스윙 결과 아래에 타이밍(ms)과 위치 오차(cm)가 표시됩니다.
- 데스크톱에서는 마우스를 움직여 조준 원을 옮기고 클릭하면 스윙합니다.

**투수 모드**
- 아래 버튼에서 구종(직구, 슬라이더, 커브, 체인지업)을 고르고, 던지고 싶은 위치를 탭합니다.
- 구종마다 속도와 변화량이 다릅니다. 컴퓨터 타자는 존 안쪽 공에 잘 반응하고, 변화구는 타이밍을 잘 못 맞춥니다.

## 규칙

- 3이닝, 이닝당 3아웃, 볼 4개 볼넷, 스트라이크 3개 삼진. 2스트라이크 이후의 파울은 스트라이크로 세지 않습니다.
- 안타, 2루타, 3루타, 홈런, 볼넷에 따라 주자가 진루하고 득점합니다.
- 타구가 외야 펜스 위로 넘어가면 홈런, 펜스를 직접 맞히면 2루타입니다.
- 야수가 낙하지점까지 달려가 잡을 수 있으면 아웃, 아니면 안타입니다. 땅볼은 야수의 수비 범위에 따라 결정됩니다.

## 실행

정적 파일이라 서버만 있으면 됩니다. `three.js`는 CDN(jsDelivr, 0.160.0 고정)에서 불러옵니다.

```bash
python3 -m http.server 8000
# 브라우저에서 http://localhost:8000
```

## 테스트

게임 규칙과 물리는 `logic.js`에 화면과 분리되어 있어서 Node에서 테스트합니다.

```bash
node --test logic.test.mjs
```

투구 경로, 스트라이크존, 스윙 판정, 타구 비거리와 홈런 판정, 볼넷과 진루, 이닝 종료, 컴퓨터 타자의 성적 범위(타율 약 .2~.4, 삼진율 약 12~35%)를 확인합니다.

## 파일

| 파일 | 역할 |
| --- | --- |
| `logic.js` | 투구, 스윙 판정, 타구 물리, 수비와 진루, 점수 계산, 컴퓨터 상대 (DOM과 three.js 없음) |
| `main.js` | 3D 장면, 입력, 게임 진행, 화면 표시 |
| `index.html` | 화면 구성과 스타일 |
| `logic.test.mjs` | `logic.js` 단위 테스트 |
